가게 공지 작성기

공지를 작성하고 JSON 내보내기를 누르면 파일이 하나 저장됩니다. 그 파일을 src/data/shop-notices/<가게slug>.json 에 넣고 배포하면 게시됩니다.

⚠️ 이 페이지에는 로그인이 없습니다. 정적 사이트라 프론트에 넣는 비밀번호는 누구나 볼 수 있어 보호 기능을 하지 못하고, 저장한 내용도 이 브라우저 밖으로 나가지 않습니다. 그래서 실제로 게시되는 경로(JSON 내보내기 → 배포)만 제공합니다.

내용 블록

추가한 공지는 이 브라우저에 임시 보관됩니다(새로고침해도 남음). 실제 게시는 내보낸 JSON 을 사이트에 반영해야 됩니다.
