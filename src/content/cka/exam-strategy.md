## 모든 문제에 같은 루틴

1. **컨텍스트/호스트 전환 명령을 복사해 실행**(지시문 맨 위). 이것이 0순위입니다.
2. 이름·네임스페이스·경로·이미지 태그를 **지시문에서 복사**합니다. 손으로 치지 않습니다.
3. 명령형으로 되는 것은 명령형으로, 안 되는 것은 `--dry-run=client -o yaml` 뼈대 + 문서 예제로.
4. **확인**합니다: `get`, `describe`, 실제 접속(`wget`), `auth can-i`, `cat 파일`.
5. `ssh` 로 들어갔다면 **`exit` 로 돌아옵니다.** 다음 문제를 엉뚱한 호스트에서 시작하기 쉽습니다.

## 시간 배분

- 2시간에 약 15~20문항 → 문항당 평균 6~8분.
- 첫 바퀴: **5분 안에 끝날 것만** 푼다. 막히면 플래그 달고 넘어간다.
- 두 번째 바퀴: 배점 큰 문제(트러블슈팅·업그레이드·etcd)에 시간을 쓴다.
- 마지막 10분: 플래그 문제의 부분 점수를 챙긴다(최소한 리소스 이름·네임스페이스라도 맞게).

## 문서 검색 요령

시험 브라우저에서는 허용된 문서만 열립니다. 검색창에 **영어 핵심어**를 넣으세요.

| 필요한 것 | 검색어 |
|---|---|
| PV·PVC·파드 예제 | `persistent volume storage pod` |
| nodeAffinity 예제 | `assign pods nodes affinity` |
| NetworkPolicy 예제 | `network policies` |
| etcd 백업 | `operating etcd` |
| kubeadm 업그레이드 | `upgrading kubeadm clusters` |
| 사이드카·init | `sidecar containers`, `init containers` |
| 프로브 | `liveness readiness probes` |
| Ingress | `ingress` |
| Gateway API | `gateway api` (쿠버네티스 문서의 개념 페이지 + 허용된 경우 gateway-api 문서) |
| kubectl 치트시트 | `kubectl quick reference` |

평소 공부할 때도 **공식 문서에서 예제를 찾아 쓰는 연습**을 하세요. 어디에 무엇이 있는지 아는 것 자체가 실력입니다.

## 터미널 요령

- 복사·붙여넣기: 원격 데스크톱 터미널에서는 `Ctrl+Shift+C` / `Ctrl+Shift+V`.
- vi 에 붙여넣기 전 `:set paste`(들여쓰기 밀림 방지).
- 긴 YAML 은 `cat <<EOF | kubectl apply -f -` 로 바로 적용할 수도 있지만, **파일로 남기면** 틀렸을 때 고치기 쉽습니다.
- 파드를 빨리 지우기: `kubectl delete pod x --force --grace-period=0`.

## 준비물과 규정(요약)

- 신분증(여권 등 영문 이름이 있는 정부 발급 사진 신분증), 조용하고 정리된 방, 웹캠·마이크, 안정적인 인터넷.
- 책상 위에 아무것도 두지 않습니다. 두 번째 모니터·휴대폰·메모지 금지. 감독관이 웹캠으로 방을 둘러보게 합니다.
- 시험 전에 PSI 의 **시스템 점검**(호환성 확인)을 반드시 해 둡니다.
- 세부 규정은 바뀌므로 공식 **Candidate Handbook** 과 **Important Instructions: CKA** 를 시험 직전에 다시 읽으세요.
