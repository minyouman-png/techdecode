# 가게 조사 도구 (/shops/ 등재용)

⚠️★**한 소스만 보고 고르면 틀린다**(2026-08-11 실측): 다이닝코드 4.8(7건)이던 집이
카카오맵에서는 **2.0(25건)**이었다. 리뷰 3~7건짜리 평점은 신호가 아니라 잡음이다.

## 순서
1. `python3 dc.py "원주 노포" "원주 국밥" …` — 후보 수집(프랜차이즈 자동 제외) → `cand.json`
2. `python3 cross.py "가게A" "가게B" …` — **다이닝코드 × 카카오맵 교차검증**
   - `카카오 n≥20 && 점수<3.5` → 자동 제외 / 양쪽 표본 부족 → 보류
   - ⚠️전화 '불일치' 대부분은 다이닝코드의 `0507` 안심번호다(뒤 4자리 같으면 동일 번호)
3. `python3 precise.py "가게"` — 영업시간을 **문맥과 함께** 확인
   (정규식만 쓰면 브레이크타임·라스트오더·요일별 시간이 뒤섞인다)
4. `python3 detail.py "가게"` — 메뉴·태그·주소 한 번에

## 발행 판정
**메뉴(가격) AND 영업시간**이 둘 다 잡혀야 발행한다. 하나라도 없으면 페이지 절반이
빈칸이 되고, 채우려면 창작이 된다 — 실존 가게에 그건 하면 안 된다.
모르는 항목은 비우고 "확인 안 됨 · 전화 권장"으로 적는다. 값이 갈리면 **양쪽 다** 적는다.

⚠️수집 범위는 좁게 유지한다. 개별 사실은 저작물이 아니지만, DB의 상당 부분을 체계적·반복
수집하면 **데이터베이스제작자의 권리**(저작권법 91조) 영역이다. 손으로 고른 소수만 발행할 것.
