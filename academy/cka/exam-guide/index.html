CKA 시험 한눈에 보기

무엇을, 어떤 방식으로, 몇 점이면 붙는지. 이 과정 전체를 어떻게 쓰면 되는지.

이 강의를 마치면

  • CKA 가 어떤 시험인지(실기형·2시간·66점) 설명할 수 있다
  • 다섯 개 출제 영역과 비중을 알고 공부 순서를 정할 수 있다
  • 이 사이트의 강의·실습·모의고사를 어떤 순서로 쓸지 안다

CKA 는 어떤 시험인가

CKA(Certified Kubernetes Administrator) 는 CNCF(Cloud Native Computing Foundation)와 리눅스 재단(The Linux Foundation)이 운영하는 쿠버네티스 운영자(관리자) 자격증입니다. 개발자용 CKAD, 보안 전문가용 CKS 와 함께 쿠버네티스 자격증의 중심에 있습니다.

가장 큰 특징은 전부 실기라는 점입니다. 보기 중에서 고르는 문제가 하나도 없습니다. 원격 데스크톱으로 실제 리눅스 터미널이 주어지고, 지시문대로 클러스터를 만지면 그 결과를 채점합니다.

항목내용
형식온라인 원격 감독(PSI), 브라우저 기반 원격 데스크톱

유효기간2년
쿠버네티스 버전v1.35 (2026년 9월 공식 페이지 기준 — 이 과정의 실습 클러스터도 v1.35)
응시료$445 (2026년 9월 기준, 할인 행사가 잦음)
참고 가능허용된 공식 문서(kubernetes.io/docs 등) — 브라우저 탭 하나

주의 응시료, 할인, 허용 문서 도메인, 쿠버네티스 버전 같은 세부 규정은 자주 바뀝니다. 결제 전과 시험 직전에 공식 시험 페이지와 응시자 안내(Candidate Handbook)를 꼭 다시 확인하세요.

2025년 개정으로 Helm·Kustomize, Gateway API, CRD·오퍼레이터, CNI·CSI·CRI 같은 확장 인터페이스가 새로 들어왔습니다. 오래된 문제집만 보면 이 부분을 놓칩니다. 이 과정은 새 교과과정을 기준으로 짰습니다.

시험장에서 실제로 벌어지는 일

  1. 문제 화면에 지시문이 뜹니다. 맨 위에 “이 문제는 이 호스트(또는 컨텍스트)에서 하세요” 라는 명령이 있습니다. 이것부터 실행합니다.
  2. 터미널에서 kubectl, vi, ssh, systemctl, etcdctl, helm 같은 도구로 과제를 합니다.
  3. 막히면 브라우저 탭에서 공식 문서를 검색해 YAML 예제를 가져옵니다.
  4. 다음 문제로 넘어갑니다. 채점은 시험이 끝난 뒤 클러스터의 최종 상태로 합니다.

결국 합격을 가르는 것은 세 가지입니다. 기본 명령이 손에 익어 있는가, 문서에서 예제를 빨리 찾는가, 고장 원인을 빨리 좁히는가입니다.

이 과정을 쓰는 법

이 학습실은 세 층으로 되어 있습니다.

  1. 강의 — 기초부터 영역별로 차례대로 읽습니다. 강의마다 끝에 확인 문제가 있습니다.
  2. 실습 터미널 — 브라우저 안에서 도는 쿠버네티스 시뮬레이터입니다. 강의마다 연결된 과제를 풀고 자동 채점을 받습니다. 설치할 것이 없습니다.
  3. 모의고사 — 실제 시험처럼 2시간, 영역별 비중에 맞춰 뽑은 과제, 부분 점수, 66% 합격선으로 칩니다.

추천 순서 1주 차: 오리엔테이션 + 기초 체력 → 23주 차: 워크로드·스토리지 → 45주 차: 아키텍처·네트워킹 → 6주 차: 트러블슈팅 → 7주 차: 실습 과제 전부 다시 → 8주 차: 모의고사 반복 + killer.sh 매일 12시간이면 8주 안에 준비할 수 있습니다. 쿠버네티스를 이미 써 봤다면 34주로 줄여도 됩니다.

실습 터미널은 연습용으로 동작을 흉내 낸 시뮬레이터입니다. 쿠버네티스의 판단 규칙(스케줄링, 롤아웃, 네트워크 정책, static pod 등)을 최대한 실제처럼 재현했지만, 진짜 클러스터와 완전히 같지는 않습니다. 그래서 다음 강의에서 실제 클러스터를 직접 만드는 법도 함께 다룹니다. 시험 전에는 반드시 진짜 클러스터와 killer.sh 에서도 손을 풀어 두세요.

여기 있는 문제는 기출이 아닙니다

CKA 응시자는 문제 내용을 공개하지 않는다는 서약에 동의합니다. 인터넷의 “기출 덤프”는 규정 위반이고, 자격이 취소될 수 있습니다. 이 과정의 과제는 공개된 교과과정 항목을 하나하나 “시험장에서 받는 형태(짧은 지시문, 정확한 이름·경로, 부분 점수)“로 새로 만든 것입니다. 교과과정 역량을 빠짐없이 연습하는 것이 가장 확실한 대비입니다.
